把夜间模式交给时钟

2026 年 10 月 30 日 前端 约 4 分钟

大多数网站把夜间模式做成一个需要主动寻找的开关。但这篇文章的默认值是：晚上十点以后，页面自己变暗。

22 点到 6 点

逻辑只有三行。读取本地时间，判断是否落在夜间区间，然后给根元素换一个属性。剩下的交给 CSS 变量：

const hour = new Date().getHours();
const night = hour >= 22 || hour < 6;
document.documentElement.dataset.theme = night ? "dark" : "light";

这段代码要尽早执行，最好放在样式表之前。否则页面会先亮一下，再突然变暗，像有人在你面前按了两次灯。

为什么按时钟

系统级设置已经能表达偏好，但很多人并不会去改它。时钟是一个更朴素的信号：天黑了，屏幕该暗一点。它不完美，却几乎不需要解释。

好的默认值，应该替用户做一次不打扰的决定。

按时钟切换还有一个好处：它不会在白天和黑夜之间反复横跳。比起跟着环境光传感器抖动，一个固定的时间区间更稳定，也更容易被理解。

一个开关

默认值不等于强制。用户手动切过之后，选择应该被记住：

themeSwitch.addEventListener("change", () => {
  const next = themeSwitch.checked ? "dark" : "light";
  document.documentElement.dataset.theme = next;
  localStorage.setItem("mirages-theme", next);
});

保存过的值优先于时钟。这样，“自动”负责第一次见面，“手动”负责之后的每一次。

这个演示把开关放在左侧抽屉的底部。打开菜单，切一下，再刷新页面，选择会留在原地。
